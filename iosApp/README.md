# iosApp

iOS host project (SwiftUI shell + Compose UIViewController).

## Structure

- `iosApp.swift`: the SwiftUI `@main` entry point, mounting the Compose UI through
  `MainViewControllerKt.MainViewController()`.
- `iosApp.xcodeproj`: the Xcode project, including a "Build Kotlin Framework" script phase that calls
  `./gradlew :composeApp:embedAndSignAppleFrameworkForXcode` during the build.
- `native/`: libssh2 + OpenSSL static libraries and headers (generated by `scripts/build-ios-native.sh`,
  not committed).

## Build

```bash
# 1) Build the native dependencies (first setup, or after changing their versions)
cd .. && ./scripts/build-ios-native.sh

# 2) Open and build with Xcode (or from the command line)
open iosApp.xcodeproj
# or
xcodebuild -project iosApp.xcodeproj -scheme iosApp -destination 'generic/platform=iOS Simulator' build
```

SSH transport engine: `libssh2` (statically linked OpenSSL); the implementation is in
`composeApp/src/iosMain/kotlin/dev/termish/ssh/SshSessionLibssh2.kt`.
